Selected work

Nine systems, from statewide dashboards to firmware on a door.

02.1

AWARE

Real-Time Governance Society, Government of Andhra Pradesh

A statewide command platform that brings weather, disaster management, agriculture and health into one set of live dashboards. Incoming data streams through Kafka and Flink, and the right department gets an alert or advisory the moment a threshold is crossed.

  • Led the team as tech lead and developer
  • Microservices: one Spring Boot service per module, joined by API and integration services
  • LLM extraction with RAG turns unstructured reports into structured data
  • GIS dashboards on PostgreSQL and Cassandra, on Azure and government servers
  • Spring Boot

02.2

Railway Kavach

TIN tag layout generation and verification, Indian Railways

Kavach is India's automatic train protection system, and it depends on RFID tags placed exactly along the track. Two tools: one generates tag layouts for OEMs from station plans and survey data; the other checks any layout against RDSO rules and reports each violation as expected versus actual.

  • YOLO model reads signal interlocking plans (SIP)
  • CAD layouts (DWG/DXF) parsed in Python via ODA File Converter
  • Rule engine applies RDSO guidelines to generate and to verify
  • Owned the verification tool end to end; Celery runs long jobs
  • Python
  • Django
  • YOLO
  • Celery
  • Angular
  • PostgreSQL
02.3

Wise-Flow & GenAI platform

Visual chatbot builder and document intelligence

Wise-Flow lets people build a chatbot by wiring blocks together: triggers, prompts, conditions, actions and knowledge sources. He designed how blocks are defined, linked, stored and executed at runtime, and built the GenAI platform underneath it.

  • RAG document search with Apache Lucene for advanced queries
  • Keycloak and Auth0 security; WebSocket for live conversation
  • Azure infrastructure: Key Vault, Blob Storage, Container Apps, Functions
  • Django APIs on AWS EventBridge and Kinesis
  • LLMs
  • RAG

02.4

Connected doors

STANLEY Access Technologies, IoT

STANLEY makes the automatic doors in hospitals, airports and stores. This portal collects data from the sensors on those doors and manages them remotely, so a service team can see why a door is stuck before they drive out.

  • Over-the-air firmware updates from the portal
  • Security certificate rotation for every device
  • Live diagnostics surfaced for service teams
  • Early IoT work: Wi-Fi connectivity and porting code to custom hardware
  • IoT
  • OTA
  • Certificates
  • Device management

Internal product used across the company

Built first for Moove, now the one place every company product handles users, roles and access. Keycloak signs people in; a custom authorization module decides what each role may do.

APWRIMS

Water Resources Department, Andhra Pradesh

A digital twin of the state's water: 31,000+ irrigation tanks, 100+ reservoirs, 2,000+ rainfall stations and groundwater across 17,334 villages. Where he started, building Angular dashboards and GIS views for live levels. The platform won a National Water Mission Award in 2019.

  • Real-time dashboards for reservoirs, rainfall and groundwater
  • GIS visualisations, built with support from NRSC, ISRO
